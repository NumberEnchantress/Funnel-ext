Welcome

One Thing At A Time is ready. Open YouTube, X or Reddit: recommendation feeds now show one item at a time, with Next, Later and (on YouTube) Queue buttons at the bottom of the page.

Everything you see is logged and kept in Firefox (see Logs). Phones can't write files on their own, so use Export or Copy on the Logs page to save them — and do so now and then, because logs kept only in Firefox are lost if the extension is removed.

Everything you see is logged. The logs live in this browser (see Logs) and are also written as plain files — out of the box into your Downloads folder. For instant, quieter writing into a folder of your choice, set up the native file writer under Files.

Files

Each day gets a folder (inside a folder for its month, e.g. 2026-10\2026-10-14) with seen.md, skipped.md, deferred.md, queued.md (readable in any text editor) and events.jsonl (every detail, machine-readable).

Firefox for Android can't write files on its own (it has no native file writer and no downloads access for add-ons). So on your phone the logs are kept inside Firefox: open Logs and use Export or Copy to save them whenever you like. Export now and then: logs kept only inside Firefox are deleted if you remove the extension or clear its data.

Set up the native file writer (one time, about a minute)
  1. Install Python 3 if you don't have it (python.org).
  2. In the One Thing At A Time project folder (next to the extension folder), open native and run install-windows.ps1 (right-click → Run with PowerShell). On macOS / Linux run ./install-unix.sh.
  3. Come back here and press Check native writer.

The writer is a small Python script that only accepts messages from this extension () and only writes inside the log folder.
